# Algoritmos

Espaço de organização dos materiais de apoio da disciplina de Algoritmos, utilizando VisuAlg. O conteúdo será ampliado à medida que materiais apropriados para compartilhamento forem recebidos.

## Sobre a disciplina

Algoritmos desenvolve o raciocínio necessário para transformar um problema em uma sequência clara de instruções. É uma base importante para as disciplinas de programação e para a solução de problemas de engenharia.

## Conteúdos sugeridos

- noções de algoritmo, variáveis, tipos de dados e operadores;
- entrada, saída e expressões no VisuAlg;
- estruturas condicionais;
- estruturas de repetição;
- vetores, matrizes e sub-rotinas; e
- decomposição de problemas e testes de mesa.

O arquivo [Conteúdos](CONTEUDOS.md) permanece reservado para registros confirmados da turma.
