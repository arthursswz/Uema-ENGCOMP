# Linguagem de Programação

Esta trilha introduz a programação estruturada utilizando a linguagem C.

## Sobre a disciplina

Programar em C ajuda a consolidar estruturas de dados, organização de programas, gerenciamento de memória e a relação entre código e computador.

## Conteúdos sugeridos

- compilação, estrutura de um programa e entrada e saída;
- tipos, variáveis, operadores e expressões;
- decisões, laços e funções;
- vetores, matrizes, cadeias de caracteres e estruturas;
- ponteiros, memória e passagem de parâmetros; e
- arquivos, modularização, depuração e boas práticas.
