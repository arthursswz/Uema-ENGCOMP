# Arquitetura e Organização de Computadores

Esta trilha apresenta como componentes de hardware e software cooperam para executar programas.

## Sobre a disciplina

Conhecer a organização interna de computadores ajuda a entender desempenho, memória, instruções, dispositivos e os limites físicos que influenciam o desenvolvimento de software.

## Conteúdos sugeridos

- representação binária, lógica digital e portas;
- organização de processadores e conjunto de instruções;
- ciclo de instrução, unidade de controle e caminho de dados;
- memória, cache e armazenamento;
- entrada, saída, interrupções e barramentos; e
- desempenho, paralelismo e relação entre hardware e software.
